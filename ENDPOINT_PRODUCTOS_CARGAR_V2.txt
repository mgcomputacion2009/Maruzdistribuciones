🎯 ENDPOINT DE CARGA DE PRODUCTOS V2 - MARUZ DISTRIBUCIONES
================================================================

📁 ARCHIVO: /var/www/maruz/app/maruz_distribuciones/api/cargar_productos_v2.py
🔧 FUNCIÓN: cargar_productos_v2() (líneas 209-302)

🌐 URL DEL ENDPOINT:
POST http://localhost:8002/api/productos/cargar_v2

📋 HEADERS REQUERIDOS:
Content-Type: application/json

✅ CAMPOS OBLIGATORIOS:
- CODIGO: Código del producto (máx. 100 caracteres)
- DESCRIPCION: Descripción del producto (máx. 65535 caracteres)

💰 CAMPOS NUMÉRICOS VALIDADOS:
- PRE_PRECIO: Precio anterior
- PRECIOA: Precio A (precio regular)
- PRECIOB: Precio B (precio especial)
- PRECIOA + IVA: Precio A con IVA incluido
- PRECIOB + IVA: Precio B con IVA incluido
- ULTIMO_COSTO: Último costo de compra
- COSTO USD: Costo en dólares
- UTIL: Utilidad/margen
- EXIS: Existencia/Stock actual

📝 CAMPOS OPCIONALES:
- ALTERNO: Código alterno
- ALMACEN: Ubicación del almacén
- UND MED: Unidad de medida
- TIPO IVA: Tipo de impuesto
- MARCA: Marca del producto
- GRUPO: Grupo de productos
- SUB GRUPO: Subgrupo específico
- BARRAS: Código de barras
- IMAGEN1, IMAGEN2, IMAGEN3: URLs de imágenes
- IMAGEN1(EDITADA), IMAGEN2(EDITADA), IMAGEN3(EDITADA): URLs de imágenes editadas
- WEB: URL web (máx. 500 caracteres)
- CATEGORIA: Categoría del producto
- Descripción Producto: Descripción detallada
- Propiedades: Propiedades del producto
- Datos técnicos: Datos técnicos
- Especificaciones: Especificaciones
- Campos de aplicación: Campos de aplicación
- Envases disponibles: Envases disponibles
- pdf: URL del PDF
- RECOMENDACIONES: Recomendaciones
- cont, PR, IDdrive, qrt: Campos adicionales

📦 ESTRUCTURA DEL PAYLOAD REQUERIDA:
{
  "productos": [
    // Array de productos
  ],
  "timestamp": "2025-09-01T07:30:00.000Z", // Opcional
  "origen": "API v2" // Opcional
}
